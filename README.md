# ShopSphere — Online Shopping System

## Overview
ShopSphere is an e-commerce web application built using Java, Spring Boot, React, and PostgreSQL. It demonstrates a microservices-based architecture for online shopping.

## Technologies
- Java and Spring Boot
- Spring Security and JWT
- Spring Data JPA and Hibernate
- Spring Cloud Eureka
- Spring Cloud Config Server
- OpenFeign
- Spring Cloud Gateway
- PostgreSQL
- React, Vite, and Material UI
- Git, GitHub, and Render

## Key Features
- User registration and login
- JWT authentication and role-based authorization
- Product management and product browsing
- Search, category filtering, and price sorting
- Shopping cart and order management
- Admin and user interfaces
- Microservices communication using OpenFeign

## Architecture
- API Gateway
- User Service
- Product Service
- Order Service
- Notification Service
- Eureka Server
- Config Server
- React frontend
